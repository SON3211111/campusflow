# 1. 프로젝트명

**CAMPUS FLOW : 선택형 AI 기반 협업 관리 플랫폼**

---

# 2. 프로젝트 개요

본 프로젝트는 대학생 팀 프로젝트에서 발생하는
업무 분담 불균형, 협업 과정의 비효율, 낮은 가시성 문제를 해결하기 위한 협업 플랫폼이다.

기존 협업툴은 기능이 분산되어 있으며
업무 배정 중심 구조로 인해 참여도 저하 문제가 발생한다.

## 핵심 구조

```
업무 배정 → ❌
업무 선택 → ✅ (Task Bucket)
```

## AI 기능

- AI는 "선택 기능"으로 제공
- 사용자는 AI 없이도 프로젝트 생성 가능
- AI는 초기 업무 구조 설계 보조 역할 수행

## 사용자 흐름

```
[기본 사용자]
홈 → 프로젝트 생성 → Task 직접 생성 → 협업

[AI 사용자]
홈 → AI Task 생성 → Task Bucket → Task 선택 → 협업
```

# 3. 차별성

기존 협업툴:
- Notion → 문서 중심
- Trello → 작업 관리 중심
- Slack → 커뮤니케이션 중심
- 문제: 기능 분산 / 협업 구조 개선 부족

본 서비스 차별점:
1. **Task Bucket 기반 업무 선택 구조** (배정이 아닌 선택)
2. **AI 기반 업무 자동 생성** (선택 기능)
3. **Dashboard 기반 협업 데이터 시각화**
4. **통합 협업 구조** (Task + Chat + 일정)

포지셔닝: `AI 보조 + 선택형 협업 + 통합 UX 플랫폼`

# 4. 메뉴 구조 (IA)

## 1Depth 메뉴

```
- 홈
- Dashboard
- AI Task
- Task Board
- Calendar
- Chat
- Settings
```

## 상세 구조

```
홈
 ├ 프로젝트 목록
 ├ 프로젝트 생성
 └ AI로 시작하기

Dashboard
 ├ 팀 진행상황
 ├ 활동 로그
 ├ 병목 구간 분석
 └ 내 작업 요약

AI Task
 ├ 과제 입력
 ├ AI 업무 생성
 └ Task Pool 등록

Task Board
 ├ Task Pool (업무 선택)
 ├ My Task (개인 보드)
 └ Team Board (전체 보드)

Calendar
 ├ 개인 시간표
 └ 공강 시간 추천

Chat
 ├ Task 기반 채팅 (댓글 기능)
 ├ 이슈 트래킹
 └ 퀵 시그널

Settings
 ├ 프로젝트 관리
 └ 알림 / 프로필
```

# 5. 핵심 기능

## AI Task Bucket
- 과제 입력 → AI 분석 → Task 생성 → 팀원이 선택
- AI는 선택 기능 (없이도 사용 가능)

## Dashboard 협업 분석
- 팀 진행률
- 활동 로그
- 병목 구간 분석
- 작업 흐름 분석

## 보조 기능
- **알림 시스템**: 실시간 알림, Task 상태 변경 알림, 멘션 알림
- **검색/필터**: Task 검색, 상태별 필터, 담당자 필터
- **온보딩 UX**: 처음 사용자 가이드, AI 사용 안내

---

# 6. UX 설계 방향

> "사용자가 복잡한 기능을 배우지 않아도 직관적으로 협업할 수 있는 구조"

1. 노션 스타일 → 탐색 구조
2. 트렐로 스타일 → 작업 관리
3. AI → 보조 기능

# 7. 기대 효과

- 협업 투명성 증가
- 참여도 기반 평가 가능
- 협업 스트레스 감소
