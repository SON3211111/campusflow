# CampusFlow 발표/시연 기능 정리

이 문서는 팀원이 PPT를 만들거나 실제 시연을 준비할 때 바로 참고할 수 있도록 CampusFlow의 현재 기능, 시연 순서, 강조 포인트, 체크리스트를 정리한 문서입니다.

## 1. 서비스 한 줄 소개

CampusFlow는 팀 프로젝트를 위해 AI가 업무를 분해하고, 팀원이 각자 업무를 가져가며, 칸반 보드/캘린더/커뮤니티/알림/대시보드로 진행 상황을 관리하는 협업형 프로젝트 관리 서비스입니다.

## 2. 발표 핵심 메시지

- AI가 프로젝트 설명을 바탕으로 업무를 자동 분해합니다.
- 팀원은 본인 장바구니로 업무를 가져가고, 즉시 보드 태스크로 연결됩니다.
- 보드에서는 업무 상태, 담당자, 마감일, 설명, 댓글, 파일, 빠른 요청 신호를 관리합니다.
- WebSocket으로 업무 생성/삭제/복원/상태 변경/컬럼 이동/내용 수정이 실시간 반영됩니다.
- 알림과 병목 리포트로 지연 위험을 팀이 빠르게 확인할 수 있습니다.
- 개인 설정에서 픽셀 아바타, 다크모드, 언어 설정을 관리할 수 있습니다.

## 3. 주요 사용자 흐름

### 흐름 A: AI 업무 분해에서 보드 관리까지

1. 사용자가 워크스페이스에 진입합니다.
2. AI 업무 분해 페이지에서 프로젝트 설명을 입력합니다.
3. AI가 카테고리별 업무를 생성합니다.
4. 팀원은 각자 본인 장바구니에만 업무를 드래그합니다.
5. 업무를 장바구니에 넣으면 3초 동안 추가 드래그가 잠깁니다.
6. 장바구니에 담긴 업무는 즉시 보드 태스크로 저장됩니다.
7. 보드에서 업무 상태, 담당자, 마감일, 상세 설명 등을 관리합니다.
8. 다른 사용자의 변경 사항은 WebSocket으로 실시간 반영됩니다.

### 흐름 B: 직접 보드에서 업무 관리

1. 워크스페이스 보드에 진입합니다.
2. 기본 목록 또는 커스텀 목록을 추가합니다.
3. 목록 안에 업무 카드를 직접 생성합니다.
4. 카드 이동 시 현재 목록 위치가 DB에 저장됩니다.
5. 새로고침 후에도 커스텀 목록과 그 안의 업무 카드 위치가 유지됩니다.

## 4. 기능 상세

### 4.1 워크스페이스

- 개인 워크스페이스와 팀 워크스페이스를 지원합니다.
- 개인 워크스페이스에서도 초대/멤버 추가가 발생하면 팀 워크스페이스로 전환됩니다.
- 워크스페이스별 그라데이션 테마가 적용됩니다.
- 워크스페이스 목록과 현재 선택 워크스페이스를 기준으로 보드/AI/캘린더/커뮤니티가 연결됩니다.

### 4.2 AI 업무 분해

- 프로젝트 설명을 입력하면 AI가 업무를 카테고리별로 분해합니다.
- 분해 결과는 세션 단위로 관리됩니다.
- 세션별 업무 카테고리와 업무 카드가 표시됩니다.
- 업무 카드 직접 추가, 수정, 삭제, 되돌리기를 지원합니다.
- 업무를 더 작게 나누는 세부 분해 기능을 제공합니다.

### 4.3 AI 업무 장바구니

- 팀원별 장바구니 슬롯이 표시됩니다.
- 사용자는 본인 장바구니에만 업무를 담을 수 있습니다.
- 다른 팀원 장바구니는 잠금 상태로 표시됩니다.
- 업무를 하나 담으면 3초 동안 추가 업무를 가져갈 수 없습니다.
- 업무가 많이 쌓이면 스크롤바 없이 스크롤 가능합니다.
- 장바구니에 담긴 업무는 로컬 세션에 저장되고, 동시에 보드 태스크로 생성됩니다.

### 4.4 칸반 보드

- 기본 목록: 상태 없음, 시작하지 않음, 진행 중, 보류 중, 완료
- 커스텀 목록 추가를 지원합니다.
- 커스텀 목록은 `Workspace.customColumns`에 저장됩니다.
- 업무 카드의 현재 목록 위치는 `Task.boardColumn`에 저장됩니다.
- 커스텀 목록에 만든 카드도 새로고침 후 같은 목록에 유지됩니다.
- 카드 드래그로 상태/목록 이동이 가능합니다.
- 카드 삭제는 소프트 삭제로 처리되며 휴지통 복원이 가능합니다.
- 마감일이 임박한 카드는 시각적으로 강조됩니다.

### 4.5 카드 상세

- 제목 수정
- 설명 수정
- 시작일/마감일 수정
- 담당자 변경
- 상태 변경
- 댓글
- 파일 첨부
- 빠른 요청 신호
  - 도움 필요
  - 피드백 필요

### 4.6 실시간 동기화

WebSocket 경로:

```text
/ws/tasks?workspaceId={workspaceId}
```

현재 동기화되는 이벤트:

- `TASK_CREATED`: 업무 생성
- `TASK_DELETED`: 업무 삭제
- `TASK_RESTORED`: 업무 복원
- `STATUS_CHANGE`: 상태 변경
- `TASK_UPDATED`: 제목/설명/시작일/마감일/담당자명/보드 컬럼 위치 변경

최근 보완 사항:

- 같은 `taskId`의 카드가 중복으로 들어가지 않도록 방어했습니다.
- `startDate` 업데이트도 WebSocket으로 반영되도록 맞췄습니다.
- `boardColumn` 이동 이벤트가 다른 화면에도 반영됩니다.
- 제목/설명/컬럼명에 따옴표나 개행이 있어도 JSON payload가 깨지지 않도록 서버 escape 처리를 추가했습니다.

### 4.7 캘린더/플래너

- 업무 시작일과 마감일을 기반으로 캘린더에 일정 막대가 표시됩니다.
- 담당자 아바타/색상으로 업무 소유자를 구분합니다.
- 마감일 기반 일정 확인과 일정 충돌 파악에 사용할 수 있습니다.
- 팀원별 시간표를 등록하고 아바타 탭으로 각 팀원의 시간표를 확인할 수 있습니다.
- `공강 종합` 버튼으로 팀원들의 공통 공강 시간을 자동 계산합니다.
- 공강 종합은 별도 공강 블록을 직접 등록하는 방식이 아니라, 등록된 수업/개인/태스크 시간을 제외한 빈 구간을 찾아 표시합니다.
- 시간표가 비어 있는 팀원도 조회가 완료되면 공강 종합 인원에 포함되며, 빈 시간표는 전부 가능한 시간으로 계산됩니다.
- 공통 공강은 30분 이상 비는 구간만 표시되어 회의/스터디 일정 조율 시연에 활용할 수 있습니다.

### 4.8 커뮤니티

- 워크스페이스 커뮤니티 영역에서 팀 커뮤니케이션을 지원합니다.
- 채널/대화/멘션 흐름을 통해 팀원 간 소통을 보조합니다.
- 업무 카드 댓글과 워크스페이스 커뮤니티는 팀 커뮤니케이션 관점에서 연결됩니다.

### 4.9 알림

- 상태 변경 알림
- 댓글/멘션 알림
- 빠른 요청 신호 알림
- 마감일 임박 알림
- 병목 업무 알림
- 헤더 알림 드롭다운과 알림 페이지에서 확인할 수 있습니다.

### 4.10 병목 감지 및 리포트

- 진행 중 또는 보류 중 상태로 일정 기간 이상 멈춘 업무를 감지합니다.
- 기본 기준은 3일입니다.
- 병목 업무가 뒤의 프로젝트 일정에 줄 수 있는 지연 영향 리포트를 제공합니다.
- 발표에서는 "팀 프로젝트에서 놓치기 쉬운 지연 위험을 자동으로 알려준다"는 점을 강조하면 좋습니다.

### 4.11 대시보드

- 팀 진행 상황을 요약합니다.
- 기여도/완료 업무/이슈 해결 흐름을 확인할 수 있습니다.
- 활동 피드로 최근 상태 변경 이력을 확인할 수 있습니다.
- 병목 업무 섹션으로 주의가 필요한 업무를 빠르게 찾을 수 있습니다.

### 4.12 개인정보 설정

- 이름/비밀번호 수정
- 가입일 표시
- 픽셀 학생 아바타 꾸미기
- 설정한 아바타가 헤더/보드/멤버/댓글 등 주요 영역에 적용됩니다.
- 다크모드 설정
- 언어 설정

### 4.13 다크모드/언어 설정

- 개인 설정에서 다크모드를 켜고 끌 수 있습니다.
- 주요 페이지의 다크모드 가시성을 보정했습니다.
- 메인 랜딩 페이지와 개인정보 설정에서 언어 선택이 가능합니다.
- 현재 언어 설정은 `localStorage` 기반으로 유지됩니다.

## 10. 현재 주의 사항

- `uploads/` 폴더는 사용자 첨부 런타임 파일이므로 커밋 대상이 아닙니다.
- 발표용 데이터는 실제 사용자 데이터와 분리하는 것이 좋습니다.
- WebSocket 테스트는 브라우저 또는 Node WebSocket 기준으로 정상입니다. PowerShell/.NET `ClientWebSocket`은 헤더 차이로 Spring에서 거절될 수 있습니다.
- AI 응답 품질은 로컬 Ollama 모델 상태에 영향을 받을 수 있으므로 발표 전 한 번 미리 생성해두는 것이 안전합니다.
