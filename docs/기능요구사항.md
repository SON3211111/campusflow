# 기능 요구사항

| **REQ-F-01** | 회원 관리 | 소셜 로그인 및 권한 | 구글, 카카오 OAuth 2.0 로그인. 가입 시 학생/교수자 권한 구분. | 상 |

| **REQ-F-04** | AI Task | Task 자율 선택(Picking) | 팀원이 공용 장바구니 업무를 자율 선택 → 즉시 본인 할당. | 상 |
| **REQ-F-05** | 업무 관리 | 칸반 보드 상태 변경 | 대기/진행 중/완료 드래그앤드롭 상태 변경. | 상 |
| **REQ-F-06** | 리포팅 | 진행 상황 대시보드 | 전체 진척도 간트 차트 및 파이 차트, 팀원별 기여도, 지연 업무 강조 표시. | 중 |
| **REQ-F-07** | 리포팅 | 요약 리포트 | 활동 로그 및 채팅 내역 기반 진행 흐름·의사결정 요약 텍스트 제공. | 상 |
| **REQ-F-08** | 커뮤니케이션 | 실시간 채팅 및 스레드 | 팀 전용 채팅방, 스레드 답글, 이모지 반응 지원. | 중 |
| **REQ-F-09** | 커뮤니케이션 | 채팅 및 업무 자동 번역 | 채팅 메시지 및 Task 내용 실시간 자동 번역. | 하 |
| **REQ-F-10** | 알림 | 통합 알림 시스템 | Task 상태 변경, 마감 임박, 이슈 발생 시 실시간 푸시 알림. | 상 |
| **REQ-F-11** | 협업 보조 | 이슈 해결 게시판 | 문제 공유 및 팀원 공동 해결 게시판. | 중 |
| **REQ-F-12** | 협업 보조 | 회의 시간 추천 | 시간표 데이터 취합 → 공통 공강 시간 추천. | 하 |
| **REQ-F-13** | 업무 관리 | 개인 워크스페이스 및 진행도 동기화 | 개인 보드 Task 상태 변경 → 팀 대시보드 진행률·기여도 실시간 동기화. | 상 |
